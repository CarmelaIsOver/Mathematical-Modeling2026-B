# 问题四覆盖布局优化记录

本轮实现了两类布局并做配对实验。最终将外围内收方案接入同一run.py的`--layout compact`，供人工演练；默认仍为original。它具有明显的本地平均收益，但最差退化超过既定20%上限，因此没有改为默认。没有修改论文和支撑材料zip，没有连接官方平台启动场次。

## 先检验27站布局

保持定位和调度规则不变，以paper定位比较原31站、平移27站、27站加起点共28站。开发集1100000—1100039中，27站平均改善10.21%，28站改善8.64%，选27站冻结。

独立集1200000—1200199中，27站在paper定位下改善8.14%，standard下改善7.97%，但最差分别慢63.05%、57.05%。固定16目标的20组压力场景平均慢9.19%，最差慢66.64%。少站点不等于更早找到第16个目标，故不接入此布局作为默认或人工演练选项。其源码和数据仅作为历史研究记录保留。

## 最终可测试方案：外围内收

保留同一组31个站点索引、全部13个内部站点和6个半径1900米的站点，将最远12个站点从半径约2513.46米移至1950米。定位方法、频道扫描顺序、调度规则、几何清除条件、16目标提前终止条件均不变。实际路线和观测仍可能随坐标变化。

只在问题四、spacing=950米时允许compact；其他组合明确拒绝。原默认布局和问题三行为保留。

覆盖依据：原网格截取的42个三角形保留连接关系。变形后所有三角形保持正方向，所有边长不超过1000米，边界是围绕原点的简单多边形，且每条边到原点的距离大于1800米。因此整个任务圆盘仍在网格覆盖内。每个目标属于一个三角形，其到三个顶点距离均不超过1000米；对任意发射半平面的法向量，三个顶点不可能全部在目标的严格反侧，因为目标是三顶点的凸组合。这给出定向目标至少一个可接收站点的保证。代码检查了全部42个面和全部边界边，而非只凭随机点判断覆盖。

## 冻结后的独立结果

开发：1400000—1400039。冻结参数后，重新使用1500000—1500199作独立集；没有沿用前一候选的留出集。每种定位策略都在相同200场景上比较original与compact。

每种布局/定位组合均清除2597个目标。两个退化超过10%的种子都是1500048和1500149。结果是本地合成数据，不是官方场景评分。

paper定位下，173组10—15目标场景全部更快，平均改善10.38%；27组16目标场景平均慢1.81%。standard相应改善10.29%、变慢1.15%。控制器不知道真实目标数量，因此不能按照事后真实N直接选择有利布局。

paper平均每场移动时间减少874.57秒，约少走4.37公里；测量数基本不变。最后一次清除后的平均覆盖检查时间从3479.81秒降至2707.81秒，减少772.00秒。减少移动是主要收益。

按场景配对Bootstrap重采样10000次、固定种子1700000，paper平均节省秒/源的95%区间为[65.59,75.84]，standard为[65.84,75.91]。这些区间只描述当前本地场景分布，不能覆盖所有可能的定向场景。

## 压力、接入与采用决定

在1600000—1600019上分别构造n10、n16、恒定+1度、恒定-1度、边界向外发射、边界切向发射，共120组配对压力场景；两布局都全部清除。固定16目标组平均改善0.31%，但最差仍慢36.03%。这支持完整性，不能消除极端效率退化。

预定默认采用门槛为：平均改善至少5%，P95不变差，慢超过10%的比例不大于5%，最差耗时比不超过1.2，全部清除并正常退出。本方案未通过最差耗时比，故只显式启用，不降低门槛、不默认替换。

22项检查通过，包含连续网格检查、冻结候选与运行入口的逐动作比较、模拟HTTP入口分派及结果标识检查。回放用户最近两场paper演练，默认布局仍精确匹配129、296条请求及对应总耗时，没有新增真实官方场次。

## 人工演练

在成果/support目录、平台问题四演练接口就绪后运行：

```powershell
$teamId = Read-Host "请输入当前登录平台的参赛队号"
python run.py --mode official --problem 4 --strategy paper --layout compact --robot-id $teamId --output compact_practice_logs
```

必须看到启动行`layout=compact`及结果`"coverage_layout": "compact"`。仅加`--strategy paper`仍使用原布局。问题三没有本轮布局修改。

## 复现

```powershell
python verify_coverage_experiments.py --layout compressed --localization paper
python verify_coverage_experiments.py --layout compressed --localization standard
```

可加`--count 1`验证入口，已核对该场景虚拟时间复现。研究脚本中compressed对应日常入口compact。脚本在自动清理的临时目录提取并校验冻结源文件，不连接官方接口。`--layout shifted`可复查已否决的27站研究。

compressed_protocol.json和compressed_sources.json保存最终候选冻结时的参数、测试集和完整原始字节。protocol.json、frozen_sources.json对应先前27站研究。文件名描述研究对象，不是额外的日常程序版本。下一轮调参不得再把这些已查看的留出集当作独立验证集。
