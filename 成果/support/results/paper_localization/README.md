# 论文启发的主动定位试验

结论：本轮不覆盖现有演练控制器。论文提供了有价值的局部测点设计依据，但本次改造没有达到预先沿用的整体性能采用门槛。没有修改论文、支撑材料压缩包，也没有运行官方演练或正式测试。

后续接入说明：按用户人工演练需求，已将冻结候选接入同一run.py的`--strategy paper`选项，默认策略仍为standard。运行模块为active_localization.py，新增策略标识及paper_measurements_selected计数；算法动作通过与冻结候选的轨迹比较核对。上文采用决定和以下历史基准数据保持不变。

## 方法与来源

- [ICRA 2012](https://josh.vanderhook.info/media/pdf/icra2012bot.pdf)、[JFR 2014](https://tokekar.com/pubs/vanderhook2014cautious.pdf)：借鉴面向最大不确定方向的侧向测量。原文的高斯估计、EKF和前后歧义模型不同于本题；本实验没有声称复现其原算法或继承其常数倍保证。
- [ICRA 2013](https://tokekar.com/pubs/tokekar2013asensor.pdf)：借鉴有界角误差的集合估计。保留全部历史有效测向的保守交集，不用概率点估计替代几何清除证书。原文无可见性限制的布点定理没有直接用于问题四。

先导候选在可行区域长方向两侧按区域尺度生成测点，对完整合法正测向区间分箱，以扩张扇形包住每个区间内的后验。它对12组/题开发场景全部清除，但问题三平均慢4.49%，问题四慢4.60%。问题四平均失败清除次数从11.50增加到86.92。候选代码保存在pilot_source.json，原始结果为pilot_*，不作为最终独立验证。

根据先导结果，将候选限制在可行区域最小包围圆半径不超过120米的末段定位。候选来自长方向两侧和当前位置到区域中心的路径。将合法正测向输出划为48段，每段扇形角度额外扩张半个分箱宽度；只有各段后验都能被半径不超过19.99米的圆包含时，才考虑该候选。按移动、切换、测量及后续清除接近时间选择位置。实际清除仍重新计算完整几何证书。

可见性筛选使用位置与方向采样得分，得分不是校准概率，更不是不失去信号的保证。没有正测向时保留几何区域和原有搜索兜底。若没有合格末段候选，调用现有next_measure启发式；问题四还保留原有两侧试探。因此这是一个组合改造，不能把全部收益单独归因于长轴方向。

全局站点与目标调度规则不变，但定位结束位置不同会改变后续实际路线，不能称作“全程访问顺序固定”的局部消融。

## 独立配对结果

开发集：930000—930039；随后冻结代码，独立集：940000—940199，每题200个场景，每个场景分别运行现有策略与候选。两策略接收相同接口规则、同一组真实场景；不同位置的测角误差由位置、频道和种子确定。控制器只获得AuditPort公开观测，测试器在运行结束后核对真实清除数。

预先沿用门槛：平均改善至少5%；P95不变差；慢超过10%的场景不多于5%；最差耗时比不超过1.2；全部清除且正常退出。问题三未通过平均改善与P95，问题四未通过平均改善。没有根据测试结果降低门槛。

## 原因与限制

问题三最差场景940169：16个目标均成功，访问站点由6增至7，移动时间增加695.51秒，测量增加8次，换频时间增加7秒，完全没有失败清除。这里的损失主要来自定位终点变化之后的路线和提前结束条件，不能归因于清除失败。

问题四平均每场移动时间减少80.19秒，但测量增加1.805次；可见性仍需要试探。最差场景940130的两策略都没有失败清除，候选多走522.57秒、多测17次。末段测点几何只解决一部分成本，尚未解决覆盖搜索与定位的全局协调。

问题三节省区间包含零，不能据此认定平均收益稳定；问题四出现小幅正收益，但仍不足以支持宣称明显优于现有方案。这不否定论文原算法在其适用模型下的价值，也不证明本候选普遍优于或劣于其他尚未比较的方案。

## 验证与复现

另外进行了80组配对压力场景：每题各20组恒定+1度、20组恒定-1度误差，接收半径1000米，问题四全部定向；两策略均全部清除。压力测试不是新的调参集。原程序16项检查通过；新增2项几何检查通过，包含1440组合法后验包围验证。几何抽样验证是实现检查，不替代连续区间外包构造的论证。

frozen_sources.json保存实验脚本及所用基础源码的原始字节和SHA256；protocol.json记录冻结时的方案与采用门槛。开发结果与冻结脚本哈希不同，仅因冻结前删除了最终策略不再调用的先导评分方法。holdout_*和stress_*均对应同一个冻结哈希。analysis.json保存最差案例及配对区间。

在成果/support目录运行：

```powershell
python verify_paper_experiments.py --problem 3
python verify_paper_experiments.py --problem 4
```

可加`--count 1`检查入口。复现从校验过的源码数据在自动清理的临时目录运行，无官方接口入口。已有留出场景已用于验收和解释，未来再据此修改后应另取新场景作独立验证。

下一步的优先问题是测点执行后的位置如何影响后续访问和16目标提前结束，以及定向场景的失去信号恢复代价；不建议继续只增加局部信息增益或盲目扩大侧移距离。
