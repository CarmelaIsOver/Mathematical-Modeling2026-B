# Q4覆盖优化试验：未通过默认接入门槛

本轮继续以多场算术平均不超过400秒/源为目标。最佳已独立验证候选为22站连续覆盖布局，加上已发现16个目标时结束新增目标搜索。独立均值486.51秒/源，未达到400目标，也未达到预先规定的至少5%改善门槛。**默认Q4保持integrated/radial，未切换为新候选。**

## 检验过的方向

开发场景2500000—2500031，分别比较：现有25站；多个21、22站布局；清除位置替换待访问站点；等待交叉方位；初始观测引导网格旋转；未来补测收益评分；达到16个已知目标后取消剩余搜索站点。阶段结果分别保存在各development文件中。

被选候选的开发均值473.88秒/源，对照501.67秒/源。其他复杂策略没有进一步改善，不纳入候选。第一次独立验证后测试的补测评分与内收参数，也未改善原开发集最佳均值，未据此改选候选或复用独立集宣称新验证。

## 22站布局的连续覆盖证明

站点为原点、999米圆周均布7点、1870米圆周均布14点。不能仅凭随机采样通过，也不能沿用旧布局“三角形各边均小于1000米”的证明。

新的证明把任务圆盘所在的正方形递归分成小正方形。对每个小块，选出距其所有位置均小于1000米的测点；再验证这些测点的凸包包含整个小块。任一块内目标、任一经过目标的闭发射半平面，都至少包含一个这样的测点。因此该目标可被探测。完全在任务圆盘外的块可排除，无法证明的块继续细分；达到计算限额仍无法证明时返回“不通过”，不会当作已覆盖。

coverage_proof.json保存细分证书。独立自动检查重新验证四角到各接收测点的距离，并用三点凸组合验证四角包含关系，再重建整棵细分树验证没有遗漏任务圆盘。有些21站候选虽通过离散采样，连续检验仍有无法证明覆盖的区域，因此未按有保证覆盖采用；检验不通过本身不等于已经证明存在盲区。

## 数量上限的使用

只有成功清除目标与仍待清除的已发现目标合计达到题目上限16时，才取消剩余发现任务；此后仍必须清除全部已知目标。没有使用平台隐藏数量或位置。10—15个已发现目标不足以触发该条件。

## 独立200场结果

在查看结果前冻结源码和protocol.json，独立种子2600000—2600199，两策略同场配对。frozen_sources.json保存源码及SHA256，完整结果见holdout.csv/json。

| 指标 | 当前25站默认 | 22站候选 |
|---|---:|---:|
| 平均秒/源 | 501.54 | 486.51 |
| P95秒/源 | 649.42 | 629.05 |
| 最差秒/源 | 741.51 | 664.66 |
| 单场≤400 | 20/200 | 35/200 |
| 全部清除并正常退出 | 200/200 | 200/200 |

均值改善3.00%，140场更快；5场退化超过10%，最差相对退化18.29%（2600188）。配对平均节省约15.03秒/源，场次bootstrap 95%区间[10.62,19.30]。这说明本地平均收益有证据，但幅度不足，不能写成已达成400目标或已验证官方效果。

平均测量次数296.02降到265.22；平均移动时间4512.77秒只降到4491.23秒。少站点主要省了扫描，新目标访问行程抵消了较多预期移动收益。现在仍缺少把覆盖位置、目标不确定区域和访问路线一起选择的有效方法；仅继续减站或微调权重不足以支持400目标。

## 压力检查与接入决定

另用2700000—2700009测试六类场景，各10场：10目标、16目标、+1度误差、−1度误差、圆周向外发射、圆周切向发射。均为最小1000米接收半径、全定向源。新旧策略60场各自全部完成，但候选在10目标、16目标及+1度误差组的均值没有改善；16目标压力案例最差相对退化26.94%。见stress.csv/json。

预设默认接入要求为全部完成、平均至少改善5%、P95不变差、超过10%退化的比例不高于5%。候选未通过均值门槛，压力测试也支持保持谨慎。因此保留当前默认，不要求用户重新演练一个已被宣布达标的方案。

研究候选在统一入口以显式layout=rings保留，用于复核，未新增版本目录；默认仍为layout=radial。本轮39项自动检查通过，包括旧策略及Q3回归、覆盖证书、观测16目标后的继续清除、10目标完整扫描、冻结动作轨迹及入口日志。论文和旧ZIP未修改。
