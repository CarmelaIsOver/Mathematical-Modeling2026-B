# Q4定位与调度联合实验

本轮发现有平均收益的候选：在200场新配对场景中，平均500.32→468.86秒/源，改善6.29%，通过预设常规验收门槛。但边界切向压力场景出现最坏46.90%的单场退化，故此次不替换现有默认。Q3仍为integrated/tight，Q4仍为integrated/radial。400秒/源目标未达到。

## 变更机制

原程序选中一个已知源后连续定位直到清除，再重排全局路线。候选每取得一次有效方位观测后，可以把更新后的可行区域放回联合路径规划，重新决定是否继续处理该源。同时，把现有Solver.next_measure的候选评分用于较大可行区域，考虑移动、接收可能性和预测后验大小；原Q4只在小区域选择额外的论文启发候选。

本轮没有实现完整POMDP或对所有未来分支的精确求解。评分中的接收可能性及后验收缩属于启发式，不能当成真实概率或覆盖证明。未用模拟器真实位置、真实方向或真实总数做控制决策。

部分定位每源最多四轮，第五轮交回原有完整定位流程。小区域清除、未知频道的完整覆盖、已知源必须清除、失败后原有光学覆盖、正常退出检查均保留。定位分步返回不会删掉未解决目标。

研究原型仅用于离线实验；源码保存在各阶段的sources.json中，运行入口及两问控制器均未改动。不需要用户为此重跑当前官方默认程序。

## 压力检验及不采用原因

每种10场，种子3400000—3400009，共60个困难场景，分别运行当前默认和组合，共120次，全部完成。接收半径1000米且全部定向；ten、sixteen分别固定10/16源，其余按生成器选择源数。outward和tangent额外将源放到半径1800米的边界，分别朝外与切向发射。它们是专门构造的困难配置，不混入常规200场均值，也不代表已知官方分布频率。

| 场景 | 原默认平均秒/源 | 组合平均秒/源 | 最坏单场耗时比 |
|---|---:|---:|---:|
| 10源、最小接收半径、全定向 | 691.07 | 662.26 | 1.055 |
| 16源、最小接收半径、全定向 | 442.38 | 420.96 | 1.230 |
| +1度误差、最小半径、全定向 | 562.11 | 538.23 | 1.029 |
| -1度误差、最小半径、全定向 | 562.71 | 544.22 | 1.050 |
| 边界朝外 | 719.03 | 728.05 | 1.241 |
| 边界切向 | 500.59 | 554.82 | 1.469 |

最坏切向案例3400001：平均356.95→524.35秒/源，移动3841.22→6213.56秒，后备3→5次，未命中30→59次。新增成本远超过少测量的收益。

进一步在同一批10个切向场景上做诊断消融（不作为新的独立验收）：原25站500.59，原22站596.59，25站新定位调度575.84，22站组合554.82秒/源。说明退化既与覆盖布局改变有关，也与中途调整定位路线有关；组合缓解了部分退化但未消除。仅凭光学后备次数减少也不能断言总成本下降，路径变化必须一起计入。

据此保留有平均收益的研究结果，但不将此次候选作为默认。下一步研究应约束定向源定位过程中的有效观测几何，重点防止离开已取得有效观测的一侧后产生长距离补测；这是待验证方向，当前没有声称它能保证改善或达到400。

