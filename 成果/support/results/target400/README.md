# 问题四400秒/源目标验证

本轮已将平均耗时明显降低，**尚未实现多场平均不超过400秒/源**。结果来自本地规则模拟，不能代替官方演练或正式测试。

## 验证口径与数据

- 主指标：每场总虚拟耗时除以该场成功清除总数，再对场次取算术平均；不按目标数加权。
- 完整性：全部目标清除，逐步计时核查通过，正常退出。
- 开发集：1800000—1800023，比较布局、任务队列、测量、光学和路线组合。
- 查看独立结果前固定候选multitour、代码快照和验证协议。
- 独立集：1900000—1900199，同一场景分别运行三个控制器，共600次运行。
- 控制器只接收AuditPort观测接口；真值和数量只用于评估，不参与决策。

protocol.json保存口径，frozen_sources.json保存候选和对照代码及SHA256。开发结果为各development文件，独立结果为holdout.json/csv，配对分析为paired_analysis.json。

候选均值的场次bootstrap 95%区间约为[501.63,526.16]秒/源。相对内收31站的平均节省为178.42秒/源，配对bootstrap区间约[169.22,187.18]。这些区间描述本地生成器采样，不保证官方分布表现。

平均移动时间从内收方案的6741.01秒降至4558.70秒；测量次数从308.24降至302.54；未命中清除次数从12.68降至7.69。运行计算时间最大约0.88秒，与数千秒的虚拟任务耗时不同。

## 实际采用的改动

1. 25站覆盖替代31站。保留内部13站及六个1900米站点，把外围12个远站合并成六个新1900米站点。形成36个正向三角形，最大边983.513米，边界为内切半径1835.259米的正十二边形。连续几何检查验证无折叠、无孔洞，覆盖1800米任务圆盘。任一目标位于某个边长不超过1000米的三角形内，任何闭发射半平面至少包含一个顶点，故保留最小接收半径下的方向覆盖。
2. 已发现且未清除目标与未访问站点共同参与路线搜索；每次行动后重新安排。采用八个近邻初始路线及有界次数的2-opt改进。位置中心与路线代价为启发式估计，不宣称全局最优。
3. 跳过已知目标的小区域或确定超出最大接收距离的站点测量。未知频道仍按网格逐站测量；已发现目标始终保留在待清除任务中。
4. 区域半径在19.99至40米之间时，在中心尝试一次低成本光学清除；失败后继续定位及完整后备搜索。仅success计入清除，不把尝试称为安全半径证明。

站点动态合并、单独按频道等待成本重排，以及大范围直接光学覆盖，开发收益不足，未纳入运行代码。

## 完整性与运行接入

六类额外压力测试各10场，共60场：10目标、16目标、固定+1度误差、固定−1度误差、圆周向外发射、圆周切向发射。均采用1000米接收半径及全定向源，全部完成并正常退出。压力场景最差约879.85秒/源，单独报告，不混入主指标；见stress.csv/json。

默认问题四入口为strategy=integrated、layout=radial；问题三默认行为保留。测试包括连续覆盖证明、待清除任务保留、未知频道完整扫描、光学未命中后继续定位、正常退出与入口日志。接入后的逐动作轨迹与冻结候选在三个开发场景完全一致，冻结源码复现入口也已验证。

## 与400目标的差距

当前均值还需再降低22.17%。按目标数分组，10目标场景平均647.18秒/源，16目标场景平均382.16秒/源。少目标场景需继续确认覆盖，固定搜索与测量成本由更少目标分摊，是目前的重要瓶颈。后续应研究利用实际观测建立连续区域覆盖证明，减少确实冗余的站点及频道扫描；不能仅因发现10个目标或长时间无信号就提前退出。

本轮采用依据是完整性通过、独立均值与P95均改善，而非400目标达成。官方表现仍待人工多场演练核实。论文与旧ZIP未更新。
