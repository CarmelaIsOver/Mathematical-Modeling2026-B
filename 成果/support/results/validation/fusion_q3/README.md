# 当前Q3与Fusion目录Q3比较

结论：当前hex/adaptive与Fusion最终推荐配置平均效率持平，尚无证据支持整体替换。Fusion原点无信号时保留大环的条件分支值得进一步验证；不能将目录名中的fusion或v3解释成Q3已全面融合最新策略。

## 对照配置与方法

- 当前：`成果/support`，默认 `integrated + hex + adaptive`。
- Fusion默认：`Mathematical-Modeling2026-B-codex-q3-q4-v3-fusion/成果/support`，默认 `integrated + original`，缩环和Q3光学试探关闭。
- Fusion推荐：该目录台账最后采用的是 `--q3-ring-guard aggressive --q3-probe-radius 60`，负观测保持关闭。根README中仍有较早只推荐aggressive的描述，本次以最终台账和实际代码为准。

三种配置使用4600000–4600199相同200个种子。各在独立Python进程加载自身控制器，统一使用当前LocalBackend和AuditPort，避免模块同名混用与不同物理模型造成假比较。静态核对发现两目录的基础solver.py完全相同、search_route函数AST相同、LocalBackend类AST相同。

策略仅获得公开观测接口；真值只供测试结束核对全部清除。本次未连接官方模拟器、未改变任一目录的运行策略。

## 本次独立同场结果

| 配置 | 场均秒/源 | P95 | 最大单场秒/源 | ≤250场数 | 完成 |
|---|---:|---:|---:|---:|---:|
| 当前hex/adaptive | **247.33** | **300.25** | 326.60 | 108/200 | 200/200 |
| Fusion默认 | 286.75 | 345.94 | 405.45 | 31/200 | 200/200 |
| Fusion推荐 | 247.38 | 302.22 | **322.06** | **111/200** | 200/200 |

Fusion推荐减当前的均值差为+0.0482秒/源。对配对差值10000次自助重采样，95%区间−1.14至+1.36，跨零。不能把0.05秒差异解读成已证实的优势。

Fusion推荐在125场更快，当前在75场更快；但Fusion有4场比当前慢超过10%，最差慢18.72%。当前没有比Fusion慢超过10%的场次，最大相对退化8.93%。较多小幅获胜与少数较大退化相抵，使总体均值接近。两者都有更好的指标，不应只选一个指标宣布全面优胜。

平均每场：当前测量111.98次、移动2360.57秒，Fusion推荐测量104.06次、移动2409.73秒。Fusion少约7.92次测量、少10.05秒切频，但多约49.16秒移动，节省基本相抵。失败清除次数均很少（当前0.435、Fusion0.49），光学覆盖回退均为0。

## 实际机制差异

| 环节 | 当前方案 | Fusion推荐配置 |
|---|---|---|
| 搜索布局 | 原点+固定1125米六点环 | 开始使用原1558.85米环；原点至少收到1个源，才改1123米环，否则保留大环 |
| 定位调度 | 得到有效观测后可返回全局任务队列；每源最多4次部分推进，然后完整定位 | 选中一个源后执行原子定位，完成该源再调度其他任务 |
| 小区域尝试 | 19.99–40米窗口；每个正观测状态最多尝试一次 | 进入定位时19.99–60米窗口；失败继续原定位 |
| 负观测 | 已启用1000米无信号距离排除的凸外包，影响区域、路径与认证 | 推荐配置未启用；可选正/负观测中垂线约束默认仅影响下一测点 |
| 已知源扫描 | 已可安全清除，或可行域到站的最小距离>1500时跳过 | 缩环开关开启时，另有“站到区域中心>1200”即跳过的启发式 |
| 搜索结束后 | 对剩余源仍做多起点2-opt路线规划 | 逐次选最近区域中心 |
| 核心安全判据 | 外包半径≤19.99米后认证清除；失败有限后备 | 同样的认证判据和基础定位后备 |

1123与1125米都满足Q3全域覆盖。1123米的最不利边界距离999.98075米，余量约0.01925米；1125米为999.11066米，余量约0.88934米。在模型精确定位条件下二者均有效，不应仅凭余量差异把1123判为不安全，也不应把半径差2米视为主要性能来源。

Fusion目录虽包含LocalizationService.advance_omni实现，但Q3生产类未接入它；最终台账明确未吸收Q3 adaptive。类/文件存在不等于执行路径已启用。

## 压力场景

4700000–4700009，每组10场，接收半径全部1000米；两种最终配置各50场全部完成。

| 组别 | 当前秒/源 | Fusion推荐秒/源 | 本组较优 |
|---|---:|---:|---|
| 10源 | **301.69** | 305.24 | 当前 |
| 16源 | **217.19** | 220.72 | 当前 |
| 固定+1° | **250.90** | 255.54 | 当前 |
| 固定−1° | **247.85** | 253.94 | 当前 |
| 源全部在任务边界 | 337.37 | **305.76** | Fusion |

边界组Fusion全部10场更快、均值改善9.37%，缩环激活数为0；其他四组激活数均为10。边界场景从原点无法收到任何源，大环站点更接近这些源，这是与代码及诊断计数一致的解释。由于两套配置同时还存在定位方式等差异，尚未做仅替换此条件分支的消融，不能把全部9.37%因果归于大环。

随机200场Fusion缩环全部激活，这组实验未覆盖到原点零接收的分支；压力测试因此提供了额外信息。压力各组按人为权重合并不能代表官方总体分布。

## 判断与下一步

1. 暂不整体替换当前Q3，平均值没有明确提升证据；原方案也不能被宣布全面优于Fusion。
2. 最值得单独试验的是“原点零接收时使用更大环”。这是公开观测条件，并非读取真实源位置。应保留当前定位器做单变量对照，验证边界收益是否能保留且普通场景不退化。
3. probe60及“中心距离1200”跳过规则可以单独消融；其与当前负观测/分步定位存在交互，不能直接相加历史收益。
4. 负观测中垂线约束是合法的几何必要条件，但在推荐配置未开启，本轮不能将其算作Fusion已实现的性能收益。

当前9场官方254.36秒/源仍是有效的未达250记录。本次本地200场两方案均约247.3，并不推翻官方结果，也不证明正式测试已经达标。

Fusion相关21项单元测试本次通过；本次未重跑其全部历史测试，也没有把185项历史台账当作本轮实测。两目录算法源码未修改。
