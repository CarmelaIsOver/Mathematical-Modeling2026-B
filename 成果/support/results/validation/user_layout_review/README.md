## 验收证据的限制

用户报告采用的820000—820199种子已在仓库早期实验中使用。可以作为重复对照，但不能仅因再次运行就称为全新独立留出集。本次事先固定3100000—3100199，每问200个同场配对场景，每个场景分别运行旧默认布局和新默认布局，不据此调参。协议及源码哈希见 protocol.json；原始指标及汇总见 paired_cases.json、paired_summary.json。它们都是本地合成场景，不能替代官方配对实验。

报告中“覆盖证书未通过，所以更小外环在几何上不可能”超出了证据：证书未通过也可能是细分深度或计算预算不够。此外“除了平均提速外各项均优于旧默认”必须限定所统计的汇总指标，不能解释为每个场景更快。此前同一22站候选的压力测试保留了单场退化26.94%的记录，不能因本轮常规样本更好而忽略。

报告关于“去掉原点后圆心不被保证覆盖”的说法也不严谨：当前模型按距离小于等于接收半径判断，圆心距七个环站均为1000米，数学上仍被覆盖。保留原点扫描合理，但不能用这个说法证明其数学必需性。这不影响当前八站布局的覆盖证明。
