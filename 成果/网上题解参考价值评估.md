# 网上题解参考价值评估

评估对象：`【B题论文】2026国赛B题参考完整论文+模型代码+结果！`。本次核查参考论文、Q1—Q4关键实现和结果表，并与当前实际代码及最新验证记录比较。结论：有局部理论和实验组织参考价值，不能直接替换当前控制器，也没有证据证明直接移植会提速。

## 1. 比较基线

当前入口为`support/run.py`：Q3采用hex/adaptive（原点加半径1125米六点环），Q4采用rings/adaptive（22站）。`完成状态.md`、`效率优化验收报告.md`和`建模论文.md`仍包含更早版本，不能据此认定当前算法。

最新Q3官方九场核查全部清除109个源、正常退出；逐场秒/源等权平均254.36，尚未达到250目标。本地400场为243.32秒/源，不能替代官方样本。依据为`support/results/validation/q3_hex_official_batch.md`及`support/results/scan_route/README.md`。

参考资料Q3的325.74与Q4的583.02秒/源来自其本地模拟器和自己的场景。误差场、样本和策略均不同，不应与我们的数字直接相减计算优化幅度。

## 3. 已确认的问题

### 3.1 Q4存在严格的覆盖反例

参考外环为半径1850米、12个等分点、相位0.20弧度；内环为半径900米8点。外环正十二边形内切半径为

`1850 cos(π/12) = 1786.962779 < 1800`。

取相邻外环点中间方向`φ=0.20+π/12`，源位置`G=1800(cosφ,sinφ)=(1611.453983,802.007520)`，辐射朝向同为φ，即26.459156度。所有站点P均满足

`(P−G)·(cosφ,sinφ) ≤ −13.037221 < 0`。

因此所有站点均位于该源辐射半平面的背面，即使接收半径取1500米也无济于事。这是解析反例，不是有限网格未通过而已。参考CSV自己也报告未覆盖率0.000296，120场清除比例均值0.99824、最小0.92308。

证据：`代码文档/问题四/问题四_策略演练与统计.py`第62行、`定向覆盖方案校验.csv`、`演练测试统计汇总.csv`。不能为少一次站点扫描而采用这套21站布局。

### 3.2 Q2后验分布不能由其假设推出

参考论文PDF物理第15页（印刷第11页），式(12)及附近文字，以及Q2代码`后验密度`函数，将面积均匀近似为距离均匀，并全程使用`(1500−r)/500`作为探测概率。例如r=500米时该式等于2，不可能是概率。

即使额外假设接收半径独立服从[1000,1500]均匀分布，正确探测概率也应在r≤1000时为1、在1000<r≤1500时为(1500−r)/500。首站位于圆心、位置按面积均匀时，极坐标面积元又要求距离密度正比于r。因此收到普通方位观测后的距离权重应为

`w(r) ∝ r × min(1,(1500−r)/500)，5<r≤1500`。

数值积分均值约855.28米，而非503.3米。这里只用这个明确的特殊情形反驳原推导；它不是官方分布，也不是任意首站通用先验。若首站不在圆心，还要考虑目标圆域与方位扇形的交集。

同页式(11)的`d cosβ=r₁`是目标处直角的正确条件，但把第二点轨迹说成以S₁G为直径的圆是错误的。固定S₁=(0,0)、G=(r₁,0)时，第二点应在直线x=r₁上（排除G）；直径圆对应的直角位于第二测点。

此外，距估计源点不超过1000米，不等于距所有可能真源均不超过1000米。参考的“必然可探测”解释不能替代当前三圆盘安全区域的证明。

### 3.3 Q4方向估计没有保留位置不确定性

`机器狗_策略.py`的`方向反演`用单个估计G构造半平面；负观测只检查距估计G不超过700米。若位置误差较大，这不能证明真实距离在1000米内，可能把超距误判成扇区外。

其跨0度的可行区间拼接也值得警惕：返回的是所选片段的端点，而非明确的完整圆周区间。更根本地说，“方向仍可能是ψ”并不意味着沿ψ选的观测点对所有可能朝向都有信号。因此原代码关于必然落在扇区内的说明过强。

### 3.4 后备和终止不具备宣称的完整性

`机器狗_策略.py`生成28米网格后执行`候选=候选[:16]`。完整网格的覆盖性质不自动适用于截断后的16点。融合流程会跳过失败三次且没有新观测的源，节点为空时退出；这可能留下已发现而未清除的源。我们的实现应继续保留未完成任务，不能照搬这种退出方式。

### 3.5 “正式结果”与本地结果混用

参考论文表10、表13列出T3/T4形式的所谓正式成绩；但`正式测试结果生成.py`明确调用本地模拟器、固定随机种子生成场景，并输出“本地仿真”编码。目录内另有正式表空白模板。这些材料口径不一致，没有可据此认定为官方正式成绩的证据。不能把它们填进自己的正式成绩表。

## 4. 可以怎样优化我们的方案

**优先补齐论文与当前算法的一致性。** 现有论文仍写Q3八站及早期基准统计，实际代码已是七站分步定位。提交前应同步覆盖证明、算法流程、同场实验和官方演练表，明确区分历史数据、本地数据与正式数据。这个改进的证据已经充分；本次仅记录差异，未改正文和PDF。

**Q2可增加有界误差指标的对照。** 线性化的两条横向误差带构成平行四边形，可得到

`D_lin = 2ε sqrt(r₁²+r₂²+2r₁r₂|cosγ|) / |sinγ|`。

在现有安全候选区内比较该近似直径、实际角楔交集直径和移动耗时，可使第二问更贴近第一问的有界误差模型。交会角接近退化时不能把线性近似当严格上界；新增指标需要重新计算，不能沿用参考最优点。此项首先改善模型解释，是否提升Q3/Q4效率需要另测。

**Q4可研究保守的方向信息辅助选点。** 初版只影响候选测点排序，不裁掉覆盖站、不删除任务。进一步可维护位置G和朝向ψ的联合可行集：正观测约束`u(ψ)·(P−G)≥0`；对已确认存在的源，只有能证明负观测点对所有G均在1000米内，才能排除全向假设并加入背向约束。若不能证明，就保留“超距或背向”的并集。全向/定向类型未知也要纳入状态。采用外包近似保留真值，再评估减少失信号试探的收益。

**Q3继续针对少源案例和搜索收尾，避免重做七站优化。** 九场官方核查中移动占75.52%；10—11源场景有较多不存在频道的扫描成本。但不能在事后最后一个源清除时提前退出。此前自适应覆盖记账和顺路检测已有失败或低收益实验，新的尝试必须提出不同机制，并在全新种子中按10—16源分层做配对比较。

任何运行策略候选都应先验证完整清除、正常退出，再比较场均秒/源、P95和单例退化；Q4必须包含全定向、最小接收半径、边界向外和相切朝向。不能拿参考资料的平均数当我们的基线，也不能把已用于选参数的场景再次称为独立留出。
